Plataforma Web Corporativa y Sistema de Cotización Inteligente — Inalumh S.A.S.
•	Desarrollado con React 18, Vite y Tailwind CSS 4, implementando una arquitectura de Single Page Application (SPA) optimizada para producción.
•	Diseñó e implementó un motor de cotización avanzado con capacidades cross-sell, generación automática de presupuestos en PDF y flujos de envío a través de WhatsApp y EmailJS.
•	Integración Backend-as-a-Service (BaaS) utilizando Supabase (PostgreSQL) para la gestión dinámica del portafolio, persistencia segura de contactos y almacenamiento de datos estructurados.
•	Uso avanzado de librerías modernas como Radix UI para accesibilidad, Framer Motion para micro-animaciones fluidas y React Router para navegación dinámica.
